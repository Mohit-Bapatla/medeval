# Screenshot Assets

These screenshots show MedEval running with synthetic seeded local data. They do
not show validated benchmark results, real users, clinical validation, healthcare
validation, production use, real patient data, or private student data.

## Files

- `01-overview-dashboard.png` - overview dashboard with local counts and status
- `02-documents-page.png` - synthetic document list
- `03-document-detail-chunks.png` - document detail and chunk inspection
- `04-datasets-page.png` - dataset list
- `05-dataset-detail-qa.png` - QA examples, answerability, categories, and risk labels
- `06-experiments-page.png` - experiment list
- `07-experiment-detail-metrics.png` - aggregate metrics and experiment detail
- `08-trace-viewer.png` - trace viewer with question, model answer, gold answer, and chunks
- `09-claim-support-and-evidence.png` - claim support and evidence details
- `10-failure-analysis.png` - failure analysis table and counts
- `11-reports-page.png` - reports page
- `12-experiment-report-preview.png` - computed experiment report preview

## Refresh Guidance

Refresh screenshots only from a local synthetic demo run. Do not use real patient
data, private student data, or screenshots that imply clinical validation,
external adoption, production use, or benchmark-grade results.
